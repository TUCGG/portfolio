## 문제

교사가 LCMS에 있는 학습 콘텐츠를 학습맵의 성취기준과 연결해 하나의 수업꾸러미로 묶고, 학습 플레이어에서 바로 실행할 수 있어야 했습니다. 수업꾸러미는 이러닝 표준인 cmi5 형식으로 내보냅니다.

cmi5에서는 블록과 AU의 ID가 상위 ID를 이어 씁니다. 게시한 뒤 구조를 옮기면 같은 콘텐츠가 다른 활동으로 기록될 수 있어서, 편집 화면과 XML 생성 규칙을 함께 설계해야 했습니다.

## 역할

React 스타터를 적용한 저장소 초기 구성부터 참여했습니다. 2026년 4월부터 10월까지 전체 커밋 668개 중 475개를 작성했고, 프론트엔드 대부분과 Express 서버 일부를 맡았습니다.

## 해결

- LCMS, 학습맵, 플레이어, 포털, SAML API를 repository 계층으로 나누고 화면은 hook을 거쳐서만 호출하게 했습니다.
- 코스 트리는 dnd-kit과 Zustand·Immer로 편집하고, 임시 저장과 이동은 낙관적 업데이트로 처리했습니다.
- `cmi5.xml`은 fast-xml-builder로 만듭니다. 입력 문자열은 DOMPurify로 정리하고, AU 실행 파라미터(콘텐츠 ID, 재생 시간, 자막, 첨부)를 넣습니다. XSD가 요소 순서까지 검사하므로 순서를 고정했습니다.
- SAML 통합 로그인과 통합 로그아웃, CSP와 frame-ancestors 보안 헤더를 붙였고, 링크형 콘텐츠는 허용한 프로토콜만 받도록 서버에서 검사합니다.
- 컨테이너가 시작될 때 환경 변수를 주입해 같은 이미지를 여러 환경에 배포할 수 있게 했습니다.

## 결과

- 테스트 파일 약 90개. Playwright E2E로 로그인, 수업꾸러미 생성, 파일 업로드, 오류 페이지 이동을 검사합니다.
- CI에서 lint, 타입 검사, 커버리지, `npm audit`, Gitleaks, Semgrep, SonarQube를 통과해야 이미지가 배포됩니다.
- 접근성 안내 모달과 툴팁 포커스를 정리해 키보드로도 저작할 수 있게 했습니다.
